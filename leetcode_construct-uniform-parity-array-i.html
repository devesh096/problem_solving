3875. Construct Uniform Parity Array I

Easy

Problem Statement

You are given an array nums1 of n distinct integers.

You want to construct another array nums2 of length n such that the elements in nums2 are either all odd or all even.

For each index i, you must choose exactly one of the following (in any order):

  • nums2[i] = nums1[i]
  • nums2[i] = nums1[i] - nums1[j], for an index j != i

Return true if it is possible to construct such an array, otherwise return false.

Constraints:

  • 1 <= n == nums1.length <= 100
  • 1 <= nums1[i] <= 100
  • nums1 consists of distinct integers.

Solution Approach (Hindi)

Problem kya hai?

Humein nums1 se naya array nums2 banana hai. Har position pe hum number ko waise ka waisa rakh sakte hain, ya kisi dusre number se subtract kar sakte hain. Last mein nums2 ke saare numbers ya to odd hone chahiye, ya saare even.

Approach kya hai?

Yeh ek observation / brain-teaser problem hai. Answer hamesha True hota hai.

Do cases socho:

1) Agar saare numbers already even hain, ya saare odd hain — to kuch mat karo. nums2 = nums1 rakh do. Condition already true hai.

2) Agar mix hai (kam se kam ek even aur ek odd) — to har number se opposite parity wala koi dusra number minus kar do.

Yaad rakho:

even − odd = odd

odd − even = odd

Isliye mix case mein saare elements odd ban jaate hain. Uniform parity mil gayi.

Agar array mein sirf 1 element hai, to usko waise ka waisa rakhna padta hai. Ek element hamesha uniform parity hota hai.

Code kaise kaam karta hai?

Upar wali reasoning se pata chalta hai ki koi bhi valid input fail nahi hota. Isliye function seedha True return karta hai. Array ko padhne ki bhi zaroorat nahi.
