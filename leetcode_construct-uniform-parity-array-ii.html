3876. Construct Uniform Parity Array II

Medium

Problem Statement

You are given an array nums1 of n distinct integers.

You want to construct another array nums2 of length n such that the elements in nums2 are either all odd or all even.

For each index i, you must choose exactly one of the following (in any order):

  • nums2[i] = nums1[i]
  • nums2[i] = nums1[i] - nums1[j], for an index j != i, such that nums1[i] - nums1[j] >= 1

Return true if it is possible to construct such an array, otherwise return false.

Constraints:

  • 1 <= n == nums1.length <= 10^5
  • 1 <= nums1[i] <= 10^9
  • nums1 consists of distinct integers.

Solution Approach (Hindi)

Problem kya hai?

Humein nums1 se naya array nums2 banana hai. Har position par ya to wahi number rakh sakte ho, ya us number me se koi chhota dusra number minus kar sakte ho. Last mein nums2 ke saare numbers ya to odd hone chahiye, ya saare even.

Approach kya hai?

Sabse chhota number bahut important hai. Usse chhota koi number nahi hai, isliye usko minus karke change nahi kiya ja sakta. Woh apni original parity (odd/even) par hi rahega.

  • Agar array ka minimum number odd hai, to hum poori array ko odd bana sakte hain. Odd numbers ko waise hi rakh do. Even numbers is minimum odd se bade honge, unko is odd se minus karne par odd mil jaayega (even − odd = odd).
  • Agar array ka minimum number even hai, to koi bhi odd number even nahi ban sakta. Odd ko even banane ke liye usse chhota odd chahiye, jo exist nahi karta. Isliye ye case tabhi true hai jab array mein koi odd ho hi na — matlab saare even hon.

Isliye simple rule:

  • minimum odd hai → true
  • minimum even hai → tabhi true jab saare numbers even hon

Code kaise kaam karta hai?

Pehle array ka minimum nikalte hain. Agar woh odd hai to seedha true return. Warna check karte hain ki kya har element even hai.

Python Code

from typing import List


class Solution:
    def uniformArray(self, nums1: List[int]) -> bool:
        # Time: O(n)  |  Space: O(1)
        mn = min(nums1)
        if mn % 2 == 1:
            return True
        return all(x % 2 == 0 for x in nums1)

Time & Space Complexity

Time: O(n)
Space: O(1)

Sirf ek baar array scan karni padti hai. Extra memory almost kuch nahi.

Examples / Dry Run

Example 1: nums1 = [1, 4, 7]
Minimum = 1 (odd) → saari array odd ban sakti hai: [1, 4-1, 7] = [1, 3, 7]
Output: true
Example 2: nums1 = [2, 3]
Minimum = 2 (even), aur 3 odd hai. 3 ko even nahi bana sakte, 2 ko odd nahi bana sakte.
Output: false
Example 3: nums1 = [4, 6]
Minimum = 4 (even), lekin koi odd nahi. Seedha rakh do: [4, 6] saare even.
Output: true
Extra: nums1 = [2, 4, 5]
Minimum = 2 (even) aur 5 odd hai → false. 2 hamesha even rahega, 5 hamesha odd.
