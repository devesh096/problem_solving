3116. Kth Smallest Amount With Single Denomination Combination

Hard

Problem Statement

You are given an integer array coins representing coins of different denominations and an integer k.

You have an infinite number of coins of each denomination. However, you are not allowed to combine coins of different denominations.

Return the k-th smallest amount that can be made using these coins.

Example 1:
Input: coins = [3,6,9], k = 3
Output: 9
Explanation: Amounts that can be made: 3, 6, 9, 12, 15, ... The 3rd smallest is 9.
Example 2:
Input: coins = [5,2], k = 7
Output: 12
Explanation: Amounts: 2, 4, 5, 6, 8, 10, 12, 14, 15, ... The 7th smallest is 12.

Constraints:

  • 1 <= coins.length <= 15
  • 1 <= coins[i] <= 25
  • 1 <= k <= 2 * 10^9
  • coins contains pairwise distinct integers.

Solution Approach (Hindi)

Problem kya hai?
Humein alag-alag denomination wale coins diye hain. Har coin ki unlimited quantity hai, lekin hum different coins ko mix nahi kar sakte. Matlab sirf ek hi type ke coin ke multiples se amount bana sakte hain (jaise 3 se: 3,6,9,12...; 5 se: 5,10,15...). Humein in sab possible unique amounts mein se k-th smallest amount nikalna hai.

Approach kya hai?
Direct list banakar sort karna possible nahi hai kyunki k 2*10^9 tak ja sakta hai – bahut bada hai.
Isliye Binary Search ka use karenge answer pe.
Hum ek mid value assume karte hain aur check karte hain ki mid tak kitne unique amounts ban sakte hain. Agar count >= k hai to smaller answer try karte hain, warna larger.

Count kaise nikaalein? (Inclusion-Exclusion)
Har coin ke multiples count karne se overlap (common multiples) double-count ho jayenge. Isliye Inclusion-Exclusion Principle lagate hain:
- Har non-empty subset of coins ke liye unka LCM nikaalo.
- Agar subset size odd hai to (mid // LCM) add karo.
- Agar even hai to subtract karo.
Ye exactly unique amounts ka count de deta hai (jaise sets ke union ke formula mein).

n <= 15 hai isliye 2^n = 32768 subsets bilkul manageable hain. Har subset pe LCM nikalna O(n) hai.

Code kaise kaam karta hai?
1. Binary search range 0 se 10^11 tak (safe upper bound).
2. check(mx) function: saare subsets iterate karke inclusion-exclusion se count nikaalta hai.
3. Jo sabse chhota mx mile jahan count >= k, wahi answer.

Yeh approach Ugly Number III (LeetCode 1201) jaisa hai, bas yahan coins ke saath general LCM use hota hai.

Python Code

from typing import List
from math import lcm
from bisect import bisect_left

class Solution:
    def findKthSmallest(self, coins: List[int], k: int) -> int:
        # Time: O(n * 2^n * log(MAX)) where n <= 15, MAX ~ 1e11
        # Space: O(1) extra (besides input)
        
        def check(mx: int) -> bool:
            """Count how many distinct amounts <= mx can be formed.
            Uses inclusion-exclusion over all non-empty subsets of coins.
            """
            cnt = 0
            n = len(coins)
            for i in range(1, 1 << n):  # all non-empty subsets via bitmask
                v = 1
                for j, x in enumerate(coins):
                    if i >> j & 1:
                        v = lcm(v, x)
                        if v > mx:
                            break  # further LCM only larger; mx//v will be 0
                m = i.bit_count()  # number of coins in this subset
                if m & 1:  # odd size -> add
                    cnt += mx // v
                else:      # even size -> subtract
                    cnt -= mx // v
            return cnt >= k
        
        # Binary search the smallest amount x such that count(x) >= k
        # Upper bound is safe: k * min(coins) <= 2e9 * 25 = 5e10
        return bisect_left(range(10**11), True, key=check)
