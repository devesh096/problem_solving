1872. Stone Game VIII

Hard

Problem Statement

Alice and Bob take turns playing a game, with Alice starting first.

There are n stones arranged in a row. On each player's turn, while the number of stones is more than one, they will do the following:

  1. Choose an integer x > 1, and remove the leftmost x stones from the row.
  2. Add the sum of the removed stones' values to the player's score.
  3. Place a new stone, whose value is equal to that sum, on the left side of the row.

The game stops when only one stone is left in the row.

The score difference between Alice and Bob is (Alice's score - Bob's score).

Alice's goal is to maximize the score difference, and Bob's goal is to minimize the score difference.

Given an integer array stones of length n where stones[i] represents the value of the i-th stone from the left, return the score difference between Alice and Bob if they both play optimally.

Solution Approach (Hindi)

Problem kya hai?

Alice aur Bob stones ka game khel rahe hain. Alice pehle start karti hai. Har turn mein player leftmost x > 1 stones hataata hai, unka sum apne score mein jodta hai, aur unke sum ke barabar ek naya stone left side pe rakh deta hai. Game tab khatam hota hai jab sirf 1 stone bachta hai.

Final answer hai (Alice ka score - Bob ka score). Alice is difference ko maximize karna chahti hai, Bob minimize.

Important Observation:

Har baar leftmost x stones ko unke sum se replace karna, prefix sum ko change nahi karta. Matlab array ka prefix sum hamesha same rehta hai. Isliye hum sirf prefix sums ke saath kaam kar sakte hain.

Approach:

1. Pehle prefix sum array banao: s[i] = stones[0] + stones[1] + ... + stones[i]

2. Ab socho current player ke paas option hai ki woh current position se aage ke kisi prefix ko le le.

3. DP define karo: f = current player ka maximum achievable score difference jab game kisi particular index se start ho.

4. Base case: jab sirf last 2 stones bache hain, player unka sum le lega → f = s[n-1]

5. Peeche se iterate karte hue:

  • Player ya to aage ka best le sakta hai (f same rahe)
  • Ya current prefix s[i] leke opponent ke best se subtract kare → s[i] - f

Isliye: f = max(f, s[i] - f)

6. Alice ko kam se kam 2 stones lene padte hain, isliye loop i = n-2 se i = 1 tak chalata hai. Final f hi answer hai.

Kyun O(n) mein ho jaata hai?

Har state sirf next state pe depend karta hai, isliye ek variable se hi kaam chal jaata hai. Nested loops ki zarurat nahi.

Python Code

from itertools import accumulate
from typing import List

class Solution:
    def stoneGameVIII(self, stones: List[int]) -> int:
        # Time Complexity: O(n)
        # Space Complexity: O(1) after prefix
        s = list(accumulate(stones))
        f = s[-1]
        for i in range(len(s) - 2, 0, -1):
            f = max(f, s[i] - f)
        return f

Time & Space Complexity

Time: O(n)
Space: O(1)

Examples

Example 1:
Input: stones = [-1,2,-3,4,-5]
Output: 5
Explanation: Alice pehle 4 stones leti hai (sum=2), Bob baaki 2 leti hai (sum=-3). Difference = 2 - (-3) = 5.
Example 2:
Input: stones = [7,-6,5,10,5,-2,-6]
Output: 13
Explanation: Alice saare stones ek saath le leti hai (sum=13). Bob ka score 0. Difference = 13.

Output: -22
Explanation: Alice ko dono stones lene padte hain (sum=-22). Difference = -22.
