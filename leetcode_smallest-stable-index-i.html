3903. Smallest Stable Index I

Easy

Problem Statement

You are given an integer array nums of length n and an integer k.

For each index i, define its instability score as max(nums[0..i]) - min(nums[i..n - 1]).

  • max(nums[0..i]) is the largest value among the elements from index 0 to index i.
  • min(nums[i..n - 1]) is the smallest value among the elements from index i to index n - 1.

An index i is called stable if its instability score is less than or equal to k.

Return the smallest stable index. If no such index exists, return -1.

Constraints:

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 10^9
  • 0 <= k <= 10^9

Solution Approach (Hindi)

Problem kya hai?

Har index i ke liye instability score nikalna hai: left side (0 se i tak) ka maximum minus right side (i se end tak) ka minimum. Jo pehla index is score ko k se chhota ya barabar rakhe, wahi answer hai. Agar koi nahi mila to -1.

Approach kya hai?

Seedha har index pe left max aur right min nikalna bhi chalega kyunki n sirf 100 hai. Better tarika yeh hai:

  • Pehle ek array banao suffix_min, jisme suffix_min[i] = i se last tak ka sabse chhota number.
  • Phir left se right chalo aur running prefix_max rakho (0 se i tak ka sabse bada).
  • Har i pe check karo: prefix_max - suffix_min[i] <= k? Haan to i return kar do.

Kyunki hum left se start karte hain, pehla match hi smallest stable index hoga.

Code kaise kaam karta hai?

Pehle last se start karke suffix minimum banate hain. Phir aage se chalte hue maximum update karte hain. Example: nums = [5,0,1,4], k = 3

  • suffix_min = [0, 0, 1, 4]
  • i=0: max=5, 5-0=5 > 3
  • i=1: max=5, 5-0=5 > 3
  • i=2: max=5, 5-1=4 > 3
  • i=3: max=5, 5-4=1 <= 3 → return 3

Python Code

from typing import List


class Solution:
    def firstStableIndex(self, nums: List[int], k: int) -> int:
        # Time: O(n), Space: O(n)
        n = len(nums)
        suffix_min = [0] * n
        suffix_min[n - 1] = nums[n - 1]
        for i in range(n - 2, -1, -1):
            suffix_min[i] = min(suffix_min[i + 1], nums[i])

        prefix_max = nums[0]
        for i in range(n):
            prefix_max = max(prefix_max, nums[i])
            if prefix_max - suffix_min[i] <= k:
                return i
        return -1

Time & Space Complexity

Time: O(n)
Space: O(n)

n chhota hai (100), isliye O(n^2) brute force bhi accept ho jata. Prefix/suffix se O(n) milta hai.

Examples

Output: 3

Example 2 Input: nums = [3,2,1], k = 1
