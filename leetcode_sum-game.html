1927. Sum Game

Medium

Problem Statement

Alice and Bob take turns playing a game, with Alice starting first.

You are given a string num of even length consisting of digits and '?' characters. On each turn, a player will do the following if there is still at least one '?' in num:

  1. Choose an index i where num[i] == '?'.
  2. Replace num[i] with any digit between '0' and '9'.

The game ends when there are no more '?' characters in num.

For Bob to win, the sum of the digits in the first half of num must be equal to the sum of the digits in the second half. For Alice to win, the sums must not be equal.

Assuming Alice and Bob play optimally, return true if Alice will win and false if Bob will win.

Solution Approach (Hindi)

Problem kya hai?

Alice aur Bob ek game khel rahe hain. Ek even length wali string num di hai jisme digits aur '?' hain. Alice pehle chalati hai. Har baar koi player ek '?' ko 0-9 kisi digit se replace karta hai. Jab koi '?' nahi bachta to game khatam.

Agar string ke pehle aadhe hisse ke digits ka sum, dusre aadhe hisse ke sum ke barabar hai → Bob jeetta hai.
Agar barabar nahi hai → Alice jeetti hai.

Dono optimal khelte hain. Alice jeetegi to true, Bob jeetega to false return karo.

Approach kya hai?

Yeh problem math + game theory se solve hoti hai. Bahut simple trick hai:

Har '?' character ko socho jaise uska expected (average) value 4.5 hai.
Kyunki 0 se 9 tak numbers ka average = (0+1+2+...+9)/10 = 45/10 = 4.5.

Ab:

  • Left half ka expected sum nikaalo (har digit ya '?' ka expected value jodke)
  • Right half ka expected sum nikaalo

Agar left expected sum ≠ right expected sum, to Alice jeet sakti hai (kyunki pehle se imbalance hai, Bob optimally khelke bhi difference zero nahi bana payega).

Agar equal hai, to Bob force karke equal sums bana dega.

Yeh isliye kaam karta hai kyunki optimal play mein Bob hamesha difference ko kam karne ki koshish karta hai, lekin expected value se pata chal jaata hai ki balance possible hai ya nahi.

Code kaise kaam karta hai?

1. ans = 0.0 rakho (expected difference ke liye)
2. Left half ke har character ka expected value ans mein add karo
3. Right half ke har character ka expected value ans se subtract karo
4. Agar final ans != 0 to Alice jeetti hai → true, warna false

Python Code

class Solution:
    def sumGame(self, num: str) -> bool:
        # Time Complexity: O(n)
        # Space Complexity: O(1)
        n = len(num)
        ans = 0.0

        def get_expectation(c: str) -> float:
            # '?' ka expected value 4.5 hai (0 se 9 tak average)
            return 4.5 if c == '?' else int(c)

        # Left half ka expected sum add karo
        for i in range(n // 2):
            ans += get_expectation(num[i])

        # Right half ka expected sum subtract karo
        for i in range(n // 2, n):
            ans -= get_expectation(num[i])

        # Agar expected difference zero nahi hai to Alice jeetegi
        return ans != 0.0

Time & Space Complexity

Time: O(n)
Space: O(1)

Examples

Example 1:
Input: num = "5023"
Output: false
Explanation: Koi '?' nahi hai. Left sum = 5+0 = 5, Right sum = 2+3 = 5. Equal → Bob wins.
Example 2:
Input: num = "25??"
Output: true
Explanation: Left expected = 2+5 = 7, Right expected = 4.5+4.5 = 9. Difference ≠ 0 → Alice wins.
Example 3:
Input: num = "?3295???"
Output: false
Explanation: Left expected = 4.5+3+2+9 = 18.5, Right expected = 5+4.5+4.5+4.5 = 18.5. Equal → Bob wins.
