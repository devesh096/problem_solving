3702. Longest Subsequence With Non-Zero Bitwise XOR

Medium

Problem Statement

You are given an integer array nums.

Return the length of the longest subsequence in nums whose bitwise XOR is non-zero. If no such subsequence exists, return 0.

Example 1:

Input: nums = [1,2,3]

Output: 2

Explanation: One longest subsequence is [2, 3]. 2 XOR 3 = 1 (non-zero).

Example 2:

Input: nums = [2,3,4]

Output: 3

Explanation: The whole array [2,3,4] has XOR = 5 (non-zero).

Solution Approach (Hindi)

Problem kya hai?
Humein ek array diya gaya hai. Humein uski sabse lambi subsequence dhundni hai jiska bitwise XOR zero na ho. Agar aisi koi subsequence nahi milti to 0 return karna hai.

Intuitive Approach:
Pehle poore array ka XOR nikaal lo.

1. Agar poore array ka XOR zero nahi hai → seedha poora array answer hai. Length = n.

2. Agar saare elements 0 hain → koi bhi subsequence ka XOR 0 hi rahega. Isliye answer = 0.

3. Agar poore array ka XOR 0 hai, lekin array mein kam se kam ek non-zero number hai → Hum kisi bhi ek non-zero number ko hata den. Naye XOR ki value wahi hataaya hua number ban jaayegi (kyunki pehle total 0 tha). Woh number non-zero hai, isliye answer = n - 1.

Yeh approach bilkul simple aur correct hai. Humein sirf ek baar array traverse karni padti hai.

Python Code

from typing import List

class Solution:
    def longestSubsequence(self, nums: List[int]) -> int:
        # Time: O(n) | Space: O(1)
        n = len(nums)
        total_xor = 0
        zero_count = 0

        for num in nums:
            total_xor ^= num
            if num == 0:
                zero_count += 1

        # Case 1: whole array XOR is already non-zero
        if total_xor != 0:
            return n

        # Case 2: all zeros
        if zero_count == n:
            return 0

        # Case 3: XOR is 0 but at least one non-zero exists
        return n - 1

Time Complexity: O(n)
Space Complexity: O(1)
