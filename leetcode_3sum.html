15. 3Sum

Medium

Problem Statement

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.

Notice that the solution set must not contain duplicate triplets.

Constraints:

  • 3 <= nums.length <= 3000
  • -105 <= nums[i] <= 105

Solution Approach (Hindi)

Problem kya hai?
Humein ek array diya gaya hai. Humein usme se aise teen numbers (triplets) dhoondhne hain jinka sum 0 ho. Aur ye triplets unique hone chahiye — matlab same numbers wale triplets dobara nahi aane chahiye.

Approach kya hai?
Sabse pehle array ko sort kar lete hain. Sort karne se numbers order mein aa jaate hain, isse duplicates avoid karna aur two-pointer technique use karna aasaan ho jaata hai.

Phir har number ko fix karte hain (outer loop). Us fixed number ke baad wale numbers pe do pointers (left aur right) chalate hain.

  • Agar teenon ka sum 0 hai → triplet mil gaya, usko result mein daal do. Phir left aur right ke duplicates skip kar do.
  • Agar sum 0 se chhota hai → left pointer aage badhao (kyunki array sorted hai, isse sum badhega).
  • Agar sum 0 se bada hai → right pointer peeche lao (isse sum ghataga).

Is tarah har possible unique triplet mil jaata hai bina extra space ke.

Code kaise kaam karta hai?
1. Array sort karo.
2. Har index i ke liye (jo pehla number fix karta hai) left = i+1 aur right = last index set karo.
3. Jab tak left < right hai, sum check karo aur pointers move karo.
4. Duplicates ko skip karke unique triplets ensure karo.

Python Code

class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        # Time: O(n^2), Space: O(1) excluding output
        nums.sort()
        n = len(nums)
        result = []

        for i in range(n - 2):
            # Skip duplicate values for the fixed number
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            left = i + 1
            right = n - 1

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                if total == 0:
                    result.append([nums[i], nums[left], nums[right]])
                    # Skip duplicates for left and right
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1
                    left += 1
                    right -= 1
                elif total < 0:
                    left += 1
                else:
                    right -= 1

        return result

Time & Space Complexity

Time: O(n²)
Space: O(1) (excluding output)

Sorting takes O(n log n), lekin overall dominant part O(n²) two-pointer loops hain. Extra space almost constant hai (sirf result list ke alawa).

Examples

Example 1:
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation: Distinct triplets jinka sum 0 hai.
Example 2:
Input: nums = [0,1,1]
Output: []
Explanation: Koi bhi triplet 0 sum nahi deta.
Example 3:
Input: nums = [0,0,0]
Output: [[0,0,0]]
Explanation: Sirf ek unique triplet possible hai.
