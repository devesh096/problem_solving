3718. Smallest Missing Multiple of K

Easy

Problem Statement

Given an integer array nums and an integer k, return the smallest positive multiple of k that is missing from nums.

A multiple of k is any positive integer divisible by k.


Example 1:

Input: nums = [8,2,3,4,6], k = 2
Output: 10
Explanation: The multiples of k = 2 are 2, 4, 6, 8, 10, 12... and the smallest multiple missing from nums is 10.

Example 2:

Input: nums = [1,4,7,10,15], k = 5
Output: 5
Explanation: The multiples of k = 5 are 5, 10, 15, 20... and the smallest multiple missing from nums is 5.

Constraints:

  • 1 <= nums.length <= 100
  • 1 <= nums[i] <= 100
  • 1 <= k <= 100

Solution Approach (Hindi)

Problem kya hai?

Humein ek array nums aur ek number k diya gaya hai. Humein k ka sabse chhota positive multiple nikalna hai jo nums mein maujood nahi hai.

Jaise k = 2 ho to multiples hain: 2, 4, 6, 8, 10, 12... Agar array mein 2,4,6,8 hain lekin 10 nahi, to answer 10 hoga.

Approach kya hai? (Aapka approach)

1. Pehle nums ke saare numbers ka ek hash table (set) banao. Isse hum jaldi check kar sakte hain ki koi number present hai ya nahi. (Yeh effectively multiples of k ka presence track karta hai.)

2. Ab k ke multiples ko chhote se bade order mein check karo: pehle k*1, phir k*2, k*3...

3. Jo pehla multiple hash table mein nahi milta (matlab value zero / missing hai), wahi answer hai. Use return kar do.

Code kaise kaam karta hai?

- present = set(nums) se hash table ban jati hai.

- Loop mein har baar multiple = k * i nikalte hain.

- Agar wo set mein nahi hai to turant return kar dete hain.

Constraints chhote hain isliye bahut fast chalega.

Time aur Space Complexity kya hai?

Time: O(n + m) jahan m missing multiple ka position hai (maximum n+1 tak hi jaayega kyunki n numbers se zyada consecutive multiples nahi ho sakte).

Space: O(n) set ke liye.

Python Code

from typing import List
from itertools import count

class Solution:
    def missingMultiple(self, nums: List[int], k: int) -> int:
        # Time Complexity: O(n + m) where m is the index of the missing multiple (at most n+1)
        # Space Complexity: O(n)
        
        # Step 1: Create hash table (set) of all numbers present in nums
        # (this effectively tracks which multiples of k are present)
        present = set(nums)
        
        # Step 2 & 3: Check multiples of k starting from smallest (k*1, k*2, ...)
        # and return the first one whose value is not in the hash table (missing)
        for i in count(1):
            multiple = k * i
            if multiple not in present:
                return multiple
