Check Divisibility by Digit Sum and Product

Easy

Problem Statement

You are given a positive integer n. Determine whether n is divisible by the sum of the following two values:

  • The digit sum of n (the sum of its digits).
  • The digit product of n (the product of its digits).

Return true if n is divisible by this sum; otherwise, return false.

Solution Approach (Hindi)

Problem kya hai?
Humein ek positive number n diya gaya hai. Humein yeh check karna hai ki kya yeh number apne digits ke sum aur product ke jod se completely divide hota hai ya nahi.

Approach kya hai?

1. Number ke saare digits nikaalo (ek-ek karke last digit lete jao).

2. Un digits ka sum (jod) calculate karo.

3. Unhi digits ka product (guna) calculate karo.

4. Ab sum + product ka total nikaalo.

5. Check karo ki original number is total se divide hota hai ya nahi (agar remainder 0 aaye to true, nahi to false).

Code kaise kaam karta hai?
Hum loop chalate hain jab tak number 0 se bada hai. Har baar last digit nikaalte hain (n % 10), sum mein jodte hain aur product mein guna karte hain. Phir number ko 10 se divide karke aage badhte hain. Ant mein original number ko total se modulo karke check karte hain.

Note: Agar number mein 0 digit ho to product 0 ho jaata hai, lekin sum hamesha kam se kam 1 hota hai, isliye zero se divide ka issue nahi aata.

Python Code

class Solution:
    def checkDivisibility(self, n: int) -> bool:
        # Time Complexity: O(log n) - number of digits
        # Space Complexity: O(1)
        original = n
        digit_sum = 0
        digit_product = 1
        
        while n > 0:
            digit = n % 10
            digit_sum += digit
            digit_product *= digit
            n //= 10
        
        total = digit_sum + digit_product
        return original % total == 0

Time & Space Complexity

Time: O(log n)
Space: O(1)

Examples

Example 1:
Input: n = 99
Output: true
Explanation: Digits = 9, 9 → Sum = 18, Product = 81 → Total = 99 → 99 % 99 == 0
Example 2:
Input: n = 23
Output: false
Explanation: Digits = 2, 3 → Sum = 5, Product = 6 → Total = 11 → 23 % 11 != 0
